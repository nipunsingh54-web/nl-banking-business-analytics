# NL Banking — Business Analytics Project

## Customer Behaviour, Transaction Performance & Risk Analysis

This project analyzes banking transaction data to understand customer engagement, transaction performance, merchant behaviour, and fraud risk.

### 📊 Project Overview

The analysis covers:

- 25,000 customers
- 100,000 transactions
- 32,457 cards
- 500 merchants

### 🛠️ Tools Used

- Excel — Data preparation, EDA, KPI analysis, hypothesis validation
- Tableau — Interactive dashboard and stakeholder reporting

### 📈 Key KPIs

| KPI | Value |
|---|---:|
| Total Transaction Value | ₹164.25 Cr |
| Average Transaction Value | ₹16,424.67 |
| Transaction Success Rate | 91.15% |
| Fraud Rate | 5.38% |

### 🔍 Analysis Areas

- Customer engagement and card ownership
- Transaction performance by channel
- Transaction value across merchant categories
- Domestic vs international transaction behaviour
- Fraud and risk analysis
- Hypothesis validation
- Business recommendations

### 💡 Key Insights

- Customers with more cards show higher transaction activity.
- International transactions have a higher average transaction value than domestic transactions.
- POS is the highest-volume transaction channel.
- Transaction values vary significantly across merchant categories.
- Observed fraud rates are similar across the available merchant risk classifications.
